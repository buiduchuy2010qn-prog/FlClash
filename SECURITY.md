# Security Policy

## Scope & Supported Versions
This repository provides an independent, GNU GPL-3.0-licensed fork of FlClash maintained for Vietnamese localization, mobile stability, push notification/widget reliability, and battery/thermal efficiency.

- Latest supported release line: `v0.9.21+`
- Only general-purpose open-source client code is distributed here; no external proxy servers, subscriptions, or user credentials are bundled.

## Reporting a Vulnerability
If you discover a security issue in this fork's modifications (such as update signature checks, local service bindings, or configuration handling):

1. Do **not** disclose exploitable details publicly before a fix is prepared.
2. Open a private vulnerability report via GitHub Security Advisories (`Private vulnerability reporting`) on this repository (or contact `@buiduchuy2010qn-prog` directly with reproduction steps and affected versions).
3. For vulnerabilities originating in the upstream **FlClash** client or **mihomo / Clash.Meta** core, please also follow upstream disclosure channels:
   - https://github.com/chen08209/FlClash/security
   - https://github.com/MetaCubeX/mihomo/security

## Copyright, License & Trademark Inquiries
Upstream authors, contributors, or rights holders who have questions or requests regarding GNU GPL-3.0 compliance, attribution, trademarks, or repository notices are invited to contact the fork maintainer privately through GitHub Security Advisories (`Private vulnerability reporting`) on [buiduchuy2010qn-prog/FlClash](https://github.com/buiduchuy2010qn-prog/FlClash) so any concern can be verified and addressed promptly.
